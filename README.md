# QF Student Journey

A live dashboard that tells the story of Education City students, from application to career, using Qatar Foundation's yearly Student Data Collection submissions (AY2011–2025).

> **Status:** Phase 2 (extraction) complete: all 60 files become 10 checked tables with one command. See [docs/ROADMAP.md](docs/ROADMAP.md) and [docs/data_dictionary.md](docs/data_dictionary.md).

## The story

| Chapter | Question |
|---|---|
| 1. Growth | How did enrolment change from 2011 to 2025? |
| 2. Getting in | How many apply, are admitted and enrol, and from which schools? |
| 3. Studying | Who are the students: nationality, gender, age, funding, internships? |
| 4. Graduating | How many finish, and how long does it take? |
| 5. After | Where are graduates one year later? |

## How it works

```
data/raw/  (Excel files, never edited)
   │  pipeline: extract → validate → metrics
   ▼
data/processed/  (clean tables, generated)
   │
   ▼
app.py  (Streamlit dashboard)
```

Once live (Phase 6), adding a new year's Excel files to `data/raw/` on GitHub triggers the pipeline automatically, and the dashboard updates.

## Project structure

```
├── pipeline/            Excel → clean tables (extract, validate, metrics)

├── requirements.txt     Exact library versions (app + pipeline)

```

## Run it locally

Requires Python 3.11.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pipeline.build        # Excel files -> data/processed/*.csv, then the tests
.venv/bin/python -m streamlit run app.py
```

`pipeline.build` stops without writing anything if a file needs a person (an unknown program spelling, a new template, numbers without a name, impossible data, …) and says exactly what and where. Every build also writes a readable [data quality report](docs/quality_report.md).

## Data

- **Source:** Student Data Collection templates submitted yearly by each Education City university, plus Qatar Foundation consolidated registration files.
- **Content:** Aggregated counts only (no individual student records).
- **Confidentiality:** Institutional data. This repository must remain **private**.
